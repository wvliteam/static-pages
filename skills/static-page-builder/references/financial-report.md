# 金融报告的页面表达

仅在制作行情、净值、收益或交易条件页面时读取。本技能消费已核验分析，不负责重新获取实时行情；需要重取或重新研究时采用适合的数据、分析工具及其规则。

- 区分交易日、行情时点、数据采集时点和净值披露日。历史快照不可标成实时信号。
- 标明币种、价格精度、复权、成交量和成交额单位。成交量不是资金净流向，不能据此声称“主力净流出”。
- 参考估值与正式披露净值分开；折溢价应使用与价格时点对应的分母，不把今天收盘价和昨天净值直接解释成今日折价。
- 分时图保留真实采样点。压缩休市时段需说明，不补造休市成交。日K、分时和均线的定义分别核对。
- 情景计算器写明固定变量、费用口径和公式，不称为价格预测。百分比影响若按乘法分解，不能直接相加。
- 格式化价格时考虑二进制浮点表示，在报价精度边界核对舍入；测试当前值、零溢价和精度中点附近结果。
- 观察区、触发条件和失效条件作为基于数据时点的条件分析呈现，不包装为保证收益或立即成交指令。
- 来源与计算说明应随页面一起交付，不把采集接口的更新时间误当交易所撮合时间。
