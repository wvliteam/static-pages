## Context

候选检查采用 [R02 研究](../../../../research/2026-11-21-priority-implementation/R02-pr-validation-ci.md) 中的独立工作流。生产组合仍运行可信 main 的代码，部署按 PR head 取静态文件。

## Decisions

- 两个固定的检查在所有以 main 为目标的 PR 上独立运行。使用事件提供的测试合并提交，核对其父提交与事件 base/head。记录三个 SHA。
- 合并就绪读取完整 Git 树；候选检查用合并检出的 docs，并对 PR head 的 Git 归档运行已有预览规则和 HTML 检查。对照 Git 树及 blob 哈希，拒绝归档属性丢弃或改写候选文件。
- 站点当前较小，先检查全部正式 HTML，并运行现有单元测试。复用现有路径和资源检查；浏览器、间接资源、线上部署验收、文档链接自动检查和分支保护设置留给各自流程。
- 本地输出放 scratch，CI 输出只用于检查；不为工作流授予部署权限，不传递候选产物给 Pages。

## Rollback

回退工作流和检查脚本即可。若未来将检查设为必需，先调整相应规则再回退。
